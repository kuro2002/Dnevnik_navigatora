# Дневник Навигатора

Личный рабочий инструмент практикующего психолога: карточки клиентов, сессии,
маркеры прогресса, ИИ-разбор транскриптов и анализ динамики.

Клинические решения и ответственность остаются у психолога. ИИ помогает
замечать закономерности и готовиться к супервизии, но не заменяет её.

## Что есть в первой версии

- **Клиенты по шифру** (`К-014`), без имён. Тип: взрослый, пара, подросток,
  родитель, родитель и ребёнок. Статус, фаза работы, контекст, контракт, анкета.
- **Запросы и цели** словами каждого участника + перевод на язык процесса,
  с историей изменений.
- **Рабочие гипотезы** с основаниями, противоречащими данными и статусом.
- **Маркеры** (шкалы 0–10 и любые другие) с полной историей замеров и графиком.
- **Сессии**: дата встречи вводится вручную и хранится отдельно от даты загрузки;
  методы; транскрипт; поля карточки из исходной таблицы и референса;
  отдельные поля «только для меня»: рефлексия, что бы сделала иначе, вопрос к супервизии.
- **Три разборщика с одинаковым форматом ответа**, чтобы их можно было сравнить:
  - локальная модель в Ollama на компьютере психолога (по Tailscale);
  - YandexGPT;
  - Claude вручную: кнопка экспорта копирует инструкцию и материалы, ответ вставляется обратно.
  Длинные транскрипты автоматически конспектируются по частям.
- **Перенос в запись только того, что выбрал психолог.** Поля «для меня» ИИ не трогает.
- **Анализ динамики** по трём направлениям: изменения у клиента относительно целей,
  качество взаимодействия, действия и навыки психолога.
- **Хронология** клиента и **печатная версия для супервизии** (сохраняется в PDF из браузера).
- **Транскрибация аудио** через `audiocpp_server` на компьютере психолога. Если компьютер
  выключен, файл ждёт в очереди и отправляется повторно.

Дальше по плану: Telegram/MAX-бот, лист «Мой профессиональный рост», касания,
кандидаты в кейсы, справочники (декодер, метафоры, оферы).

## Как устроено

```
VPS (Россия, в сети Tailscale)            Компьютер психолога (Windows, в сети Tailscale)
┌──────────────────────────────┐          ┌───────────────────────────────────┐
│ сайт (FastAPI) + SQLite      │ ───────▶ │ Ollama :11434  (разбор)           │
│ ffmpeg: аудио → WAV 16 кГц   │ ───────▶ │ audiocpp_server :8080 (расшифровка)│
│                              │ ───────▶ YandexGPT API                        │
└──────────────────────────────┘
```

Сайт доступен только внутри сети Tailscale.

## Запуск на сервере

1. Установите Docker и Tailscale, подключите сервер к своей сети Tailscale.
2. `cp .env.example .env` и заполните: пароль, секрет, адреса компьютера в Tailscale,
   ключ YandexGPT (если нужен).
3. `TAILSCALE_IP=$(tailscale ip -4) docker compose up -d --build`
4. Откройте `http://<имя-сервера-в-tailscale>:8000`.

База и аудио лежат в `./data`. Делайте резервную копию этой папки.

## Компьютер психолога (Windows)

- **Tailscale** — установить и войти в ту же сеть.
- **Ollama** — установить, затем `ollama pull qwen3:14b`. Чтобы сервер мог к ней
  обращаться по сети, задайте переменную окружения `OLLAMA_HOST=0.0.0.0` и перезапустите Ollama.
- **audio.cpp** — скачать сборку CUDA для Windows (для RTX 50xx нужна сборка под CUDA 12.8+ /
  13.x), установить модель для русского языка (например, GigaAM v3) и запустить
  `audiocpp_server --config server.json`, где сервер слушает `0.0.0.0:8080`.
  Имя модели укажите в `NAV_ASR_MODEL`.

## Разработка

```
pip install -r requirements-dev.txt
NAV_PASSWORD=demo uvicorn app.main:app --reload
pytest
```

Инструкции для моделей — в `app/analysis/prompts.py`. При их изменении увеличивайте
`PROMPT_VERSION`: версия сохраняется с каждым разбором, чтобы сравнения были честными.
